This project demonstrates data cleaning and transformation techniques using Power Query, including splitting columns, merging columns, and preparing structured data for analysis.

Merging multiple columns
Cleaning and transforming data
Changing data types
Preparing data for analysis
Creating a structured and analysis-ready dataset
